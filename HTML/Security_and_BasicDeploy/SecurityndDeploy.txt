Security: 

1. XSS Attack: Cross-Site Scripting 
* On form submission you can run javascript. 
* A hacker will create a malicious/virus js code 
* He will introduce a button inside iframe website [ Ads ] 
* Data will be stored in database. 
* We access data from database using queries/commands 
* They will put these queries in your text fields 
* Validate input data
