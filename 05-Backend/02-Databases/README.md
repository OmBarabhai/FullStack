# Databases — Lambda 4.0

Database-design notes from the AlgoCamp Lambda 4.0 course.

## Course lecture

- [Section 10 — Designing DB Schema](01-Database-Schema-Design-Section-10.md)

The Section 10 revision covers the instructor's design approach and the available Booking.com worked example: requirements, entities, relationships, join tables, room modelling, date-wise availability, indexing, space–time trade-off and overbooking risk.

## Coverage boundary

The instructor announces Twitter DB schema design as the second exercise. The detailed Twitter walkthrough is not present in the transcript and supporting notes currently available in the Library, so it has not been invented or marked complete.

The broader database concepts in the Lambda master revision are overview material. Use this folder for the lecture-specific DB design walkthrough.

## Revision rule

Start with the Section 10 note. Keep additional database lecture notes in this folder as the corresponding original transcript or course material becomes available. Do not create separate files for every small concept.
