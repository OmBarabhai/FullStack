# What is ES6?

**ES6** stands for **ECMAScript 2015**, the sixth major version of the ECMAScript standard.

ECMAScript is the official specification that defines how JavaScript should work.

Before ES6, JavaScript lacked many features that developers needed for building large applications. ES6 introduced modern syntax and programming features that made JavaScript:

- Cleaner
- Easier to read
- Easier to maintain
- More powerful
- Better suited for large applications

Today, almost every modern JavaScript project uses ES6+ features.
