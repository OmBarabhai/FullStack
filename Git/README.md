# Git - Version Control System

## 📚 Overview

Git is the **industry-standard version control system** for managing code changes and collaborating with teams.

- ✅ Repository initialization
- ✅ Staging and committing
- ✅ Branching and merging
- ✅ Remote repositories

- ✅ Collaborative workflows

## 🚀 **Essential Commands**

```bash
# Initialize
git init
git clone <url>

# Staging & Committing
git add <file>
git commit -m "message"
git push

# Branching
git branch <name>
git checkout <branch>
git merge <branch>

# Viewing History
git log
git diff
git status
```

---

## 📊 **Workflows**

1. **Personal Projects** - Simple branching
2. **Team Projects** - Feature branches with pull requests
3. **Release Management** - Release branches and tags

---

## 💡 **Best Practices**

- Write meaningful commit messages
- Create feature branches for new work
- Review code before merging
- Keep commits atomic and focused
- Use descriptive branch names
