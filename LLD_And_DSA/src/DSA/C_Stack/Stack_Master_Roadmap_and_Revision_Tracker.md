## How to use this file

- **Independent** = rebuilt/solved without looking at a solution.
- **Solved** = submission accepted or user confirmed completed, but independent reconstruction is not confirmed.
- **Attempted** = code written/reviewed; acceptance or independent reconstruction is not confirmed.
- **To do** = not yet completed.
- **R1 / R2 / R3** are the only revision rounds:
  - **R1:** 2–3 days later — rebuild from memory.
  - **R2:** about 7 days later — solve/trace without notes.
  - **R3:** about 30 days later — quick recall; retry if weak.
- Mark a revision `✓` only after doing it without looking. A solved problem is not automatically mastered.
