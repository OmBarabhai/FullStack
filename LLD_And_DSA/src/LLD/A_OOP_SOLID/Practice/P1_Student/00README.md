# P1 - Student Management System

## Objective

Practice creating classes and objects by designing a simple Student Management System.

---

# Concepts Used

- Class
- Object
- Fields
- Object Creation

---

# Problem Statement

A college wants to store basic information about students.

Design a `Student` class.

---

# Requirements

Fields

- rollNumber
- name
- age
- course

---

# Tasks

## Task 1

Create a Student class.

---

## Task 2

Create 5 Student objects.

---

## Task 3

Assign different values.

---

## Task 4

Print all student details.

---

# Expected Learning

- Create multiple objects
- Store different values
- Understand object independence

---

# Rules

❌ Constructors

❌ Getters/Setters

❌ Arrays
