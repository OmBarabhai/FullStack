## 📚 Key Concepts

### **1. FSx Services**

FSx provides fully managed file systems optimized for specific use cases:

- **FSx for Windows File Server**: Fully managed Windows file shares with Active Directory integration
- **FSx for Lustre**: High-performance computing file system for scientific and ML workloads
- **FSx for NetApp ONTAP**: Enterprise-class file storage with advanced data management
- **FSx for OpenZFS**: High-performance POSIX file systems with snapshots

### **2. AWS Directory Service**

Directory Service provides managed directory services for identity and access:

- **AWS Managed Microsoft AD**: Full Active Directory in AWS with on-premises synchronization
- **Simple AD**: Simplified Active Directory for basic user and group management
- **AD Connector**: Bridge to on-premises Active Directory for hybrid identity

### **3. Enterprise Integration**

- **Single Sign-On**: Unified authentication across AWS services and applications
- **User & Group Management**: Centralized identity and access control
- **Seamless Integration**: Works with existing Active Directory infrastructure
- **Compliance & Audit**: Detailed logging for compliance requirements
