# DevOps Day 31: CloudWatch & Logs - Advanced Log Analysis

## 📖 Overview

Day 31 deepens CloudWatch knowledge with focus on log aggregation, analysis, and insights. This practical project teaches how to collect logs from distributed systems, search through vast amounts of log data, and extract actionable insights for troubleshooting and monitoring.

---

## 🎯 Learning Objectives

✅ Set up CloudWatch Log Groups and Streams  
✅ Configure log agents on EC2 instances  
✅ Use CloudWatch Logs Insights for analysis  
✅ Create metrics from logs  
✅ Implement log-based alerting  

---

## 📚 What You'll Learn

This project transforms raw log data into operational intelligence.

### Key Topics:

- **CloudWatch Logs Fundamentals**: Log Groups, Streams, and log organization patterns
- **Log Agent Installation**: Setting up CloudWatch agent and CloudWatch Logs agent on EC2 instances
- **Log Aggregation**: Collecting logs from multiple instances into centralized repositories
- **CloudWatch Logs Insights**: Using powerful query language to search and analyze logs
- **Metric Filters**: Creating CloudWatch metrics from log data for monitoring and alerting
- **Log Analysis Patterns**: Common queries for troubleshooting, performance analysis, and auditing
- **Systems Manager Integration**: Using AWS Systems Manager Session Manager for instance access
- **Cost Management**: Managing log storage and retention policies
