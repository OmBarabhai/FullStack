# DevOps Day 35: S3 Events & Hosting - Serverless Applications with S3

## 📖 Overview

Day 35 focuses on using S3 as an event source and enabling serverless architectures. This practical module demonstrates how S3 events can trigger Lambda functions and other AWS services, enabling event-driven application patterns. Additionally, it covers hosting static websites and single-page applications directly on S3.

---

## 🎯 Learning Objectives

✅ Configure S3 event notifications  
✅ Integrate S3 with Lambda for serverless processing  
✅ Host static websites on S3  
✅ Implement CloudFront distribution for S3 content  
✅ Design event-driven architectures with S3  

---

## 📚 What You'll Learn

This project demonstrates serverless application patterns centered on S3.

### Key Topics:

- **S3 Events**: Object-created and object-removed event notifications
- **Event Destinations**: SNS, SQS, and Lambda as event targets
- **Lambda Integration**: Triggering Lambda functions on S3 events for automated processing
- **Static Website Hosting**: Configuring S3 for web hosting with proper bucket policies
- **CloudFront Distribution**: Using CloudFront CDN for global content delivery and HTTPS
- **Single Page Applications**: Hosting React, Vue, Angular, and other SPAs on S3
- **Event-Driven Patterns**: Building reactive systems where S3 events drive processing workflows
