# 1️⃣ Types of Operating System

---

## 🖥️ Single User - Single Tasking

### 📌 Example

- MS-DOS

### 📖 Meaning

One user can perform:

- One task at a time

---

## 🖥️ Single User - Multi Tasking

### 📌 Example

- Windows

### 📖 Meaning

One user can perform:

- Multiple tasks simultaneously

### 📌 Example Tasks

- Browser
- VS Code
- Music

running together.

---

## 🖥️ Multi User - Multi Tasking

### 📌 Example

- UNIX
- Linux

### 📖 Meaning

Multiple users can:

- Access system
- Run multiple tasks

at the same time.

---
