# ❓ What is Single User Single Tasking OS?

## ✅ Answer

> Single User Single Tasking OS allows one user to perform only one task at a time.

### 📌 Example

* MS-DOS

---

# ❓ What is Single User Multi Tasking OS?

## ✅ Answer

> Single User Multi Tasking OS allows one user to run multiple tasks simultaneously.

### 📌 Example

* Windows

---

# ❓ What is Multi User Multi Tasking OS?

## ✅ Answer

> Multi User Multi Tasking OS allows multiple users to access system and run multiple tasks simultaneously.

### 📌 Example

* UNIX
* Linux

---

# ❓ Why Linux is Called Multi User OS?

## ✅ Answer

> Linux allows multiple users to log in and use system resources at the same time.

---

# ❓ What is Client?

## ✅ Answer

> Client is system or device that requests services from server.

### 📌 Examples

* Browser
* Laptop
* Mobile

---

# ❓ What is Server?

## ✅ Answer

> Server is system that provides services/resources to clients.

### 📌 Examples

* Web Server
* Database Server
* Mail Server

---

# ❓ Difference Between Client and Server?

| Client              | Server            |
| ------------------- | ----------------- |
| Requests service    | Provides service  |
| Front-end user side | Back-end provider |
| Lightweight         | Powerful system   |

---

# ❓ What is Linux Architecture?

## ✅ Answer

Linux architecture consists of:

```text
User → Shell → Kernel → Hardware
```

---

# ❓ What is Shell?

## ✅ Answer

> Shell is interface between user and kernel that accepts commands from user.

---

# ❓ What is Kernel?

## ✅ Answer

> Kernel is core part of operating system that manages hardware resources.

---

# ❓ What are Types of Shell?

| Shell | Full Form          |
| ----- | ------------------ |
| SH    | Bourne Shell       |
| BASH  | Bourne Again Shell |
| KSH   | Korn Shell         |
| CSH   | C Shell            |

---

# ❓ What is BASH?

## ✅ Answer

> BASH is most commonly used Linux shell used for commands and shell scripting.

---

# ❓ What is HTTP?

## ✅ Answer

> HTTP is protocol used for web communication.

---

# ❓ What is FTP?

## ✅ Answer

> FTP is protocol used for file transfer between systems.

---

# ❓ What is DNS?

## ✅ Answer

> DNS converts domain names into IP addresses.

### 📌 Example

```text
google.com → IP Address
```

---

# ❓ What is DHCP?

## ✅ Answer

> DHCP automatically assigns IP addresses to devices in network.

---

# ❓ What is SMTP?

## ✅ Answer

> SMTP protocol is used to send emails.

---

# ❓ What is IMAP?

## ✅ Answer

> IMAP protocol is used to receive emails.

---

# ❓ Why Linux is Important in DevOps?

## ✅ Answer

Linux is important because:

* AWS servers use Linux
* Docker runs on Linux
* Kubernetes uses Linux
* CI/CD tools run on Linux

---

# ❓ Why Linux is Preferred for Servers?

## ✅ Answer

Linux is preferred because it is:

* Secure
* Stable
* Lightweight
* Open source
