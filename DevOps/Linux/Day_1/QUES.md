# 🧠 Most Asked Beginner Questions

---

# ❓1. What is Operating System?

## ✅ Answer

> Operating System is software that acts as interface between user and hardware and manages system resources.

---

# ❓2. What is Linux?

## ✅ Answer

> Linux is an open-source UNIX-like operating system created by Linus Torvalds in 1991.

---

# ❓3. Why Linux is Popular in Servers?

## ✅ Answer

Linux is popular because it is:
- Secure
- Stable
- Lightweight
- Fast
- Open source

---

# ❓4. What is Kernel?

## ✅ Answer

> Kernel is the core part of operating system that manages hardware resources and communication between hardware and software.

---

# ❓5. What is Shell?

## ✅ Answer

> Shell is interface between user and kernel that accepts commands from user.

---

# ❓6. Difference Between CLI and GUI?

| CLI | GUI |
|---|---|
| Command based | Graphical |
| Faster | Easier |
| Used in servers | Used in desktop |
| Less resource usage | More resource usage |

---

# ❓7. What is Open Source?

## ✅ Answer

> Open source means source code is publicly available and anyone can view, modify, and distribute it.

---

# ❓8. Difference Between Linux and Windows?

| Linux | Windows |
|---|---|
| Open source | Closed source |
| More secure | Less secure |
| CLI powerful | GUI focused |
| Mostly free | Paid |

---

# ❓9. What is UNIX?

## ✅ Answer

> UNIX is an operating system developed in 1969 at Bell Labs and Linux is UNIX-like operating system.

---

# ❓10. Who Created Linux?

## ✅ Answer

> Linux was created by Linus Torvalds in 1991.

---

# ❓11. What is TUI?

## ✅ Answer

> TUI stands for Text User Interface where interaction happens using text-based screens.

---

# ❓12. What is RPM?

## ✅ Answer

> RPM stands for Red Hat Package Manager used to install software packages in Red Hat based Linux systems.

---

# ❓13. What is RHEL?

## ✅ Answer

> RHEL stands for Red Hat Enterprise Linux used mostly in enterprise servers.

---

# ❓14. Why DevOps Engineers Use Linux?

## ✅ Answer

Because:
- Most servers run Linux
- Cloud platforms use Linux
- Docker/Kubernetes work on Linux
- Automation is easier

---

# ❓15. What are Linux Distributions?

## ✅ Answer

> Linux distributions are customized versions of Linux with different tools and package managers.

Examples:
- Ubuntu
- CentOS
- RHEL
- Debian
