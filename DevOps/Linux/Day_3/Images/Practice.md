# 📌 File Practice

## Create File

```bash
touch ec2.txt
```

---

## Create Multiple Files

```bash
touch ec2.txt rds.txt sns.txt
```

---

# 📌 Read File

```bash
cat ec2.txt
```

---

# 📌 Write Into File

## Replace Content

```bash
echo "AWS EC2 Notes" > ec2.txt
```

---

## Append Content

```bash
echo "Linux Is Important For DevOps" >> ec2.txt
```

---

# 📌 Rename File

```bash
mv sns.txt notification.txt
```

---

# 📌 Copy File

```bash

```

---

# 📌 Delete File

```bash
rm rds.txt
```

# 📌 Linux Important Concepts Learned

| Symbol | Meaning            |
| ------ | ------------------ |
| `>`    | Replace content    |
| `>>`   | Append content     |
| `.`    | Current directory  |
| `..`   | Previous directory |
| `~`    | Home directory     |
| `/`    | Root directory     |

---

# 📌 Linux Case Sensitive

These are different:

```text
notes.txt
Notes.txt
NOTES.txt
```

Linux treats them separately.

---

# 📌 Current Linux Path Understanding

```text
/home/om/practice/aws
```

Meaning:

```text
/         → Root
home      → Users folder
om        → My user
practice  → My practice folder
aws       → Current folder
```
