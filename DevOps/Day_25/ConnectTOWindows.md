# Connect Windows EC2 Using Remote Desktop (RDP)

---

# Step 1 — Launch Windows EC2

Select:
```text
Windows Server
````

Example:

```text id="kxjlwm"
Windows Server 2022
```

---

# Step 2 — Configure Security Group

Go to:

```text id="wzbd1o"
EC2 → Security Groups
```

Select:

```text id="t4j1rl"
default
```

Go to:

```text id="v1vbt6"
Inbound Rules
→ Edit Inbound Rules
```

Add Rule:

```text id="0gpxpj"
Type      → RDP
Protocol  → TCP
Port      → 3389
Source    → My IP
```

Save Rules.

---

# Step 3 — Get Windows Password

Go to:

```text id="jtrnwb"
EC2 → Instances
```

Select:

```text id="e5nx95"
Windows Instance
```

Click:

```text id="fg8s4d"
Actions
→ Security
→ Get Windows Password
```

---

# Step 4 — Upload PEM File

Upload:

```text id="a8l9l4"
.pem file
```

Example:

```text id="t6ckm2"
Om-Aws.pem
```

Click:

```text id="9j7z8f"
Decrypt Password
```

---

# Step 5 — Copy Credentials

Username:

```text id="mng9n0"
Administrator
```

Password:

```text id="jvjlwm"
Generated by AWS
```

Copy password.

---

# Step 6 — Open Remote Desktop

Open:

```text id="8a2q3s"
Remote Desktop Connection
```

Shortcut:

```text id="9qztqo"
mstsc
```

---

# Step 7 — Enter Public IP

Example:

```text id="p6n7r2"
13.xx.xx.xx
```

Click:

```text id="5yw4ji"
Connect
```

---

# Step 8 — Login

Username:

```text id="7krxwu"
Administrator
```

Password:

```text id="e7yjlwm"
Paste copied password
```

Click:

```text id="zjlwm2"
OK
```

Accept certificate warning.

---

# Final Flow

```text id="8j5srb"
Launch Windows EC2
↓
Add RDP Rule (3389)
↓
Actions → Security → Get Windows Password
↓
Upload PEM File
↓
Decrypt Password
```
