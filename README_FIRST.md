# DSA Interview System — Starter Guide

This is an additive interview-preparation system for the existing FullStack repository. It does not replace or rewrite existing notes or Java code.

## New files

- `02-DSA/00_DSA_Interview_Master_Roadmap.md` — three-year plan and daily workflow.
- `02-DSA/00_DSA_Pattern_Master_Index.md` — pattern order and priorities.
- `02-DSA/00_DSA_Progress_Inventory.md` — existing material audit and known previous practice.
- `02-DSA/01-Arrays-Strings-and-Hashing/Pattern_01_Arrays_and_Hashing_Core_Revision_v1.md` — first active pattern.
- `09-Company-Preparation/06-Company-Wise/Company_Wise_DSA_Interview_Index.md` — company sources, target groups and workflow.
- `09-Company-Preparation/06-Company-Wise/Company_Problem_Tracker_Template.md` — canonical company problem tracking.

## Rules

1. Preserve existing DSA subject folders and revision notes.
2. Keep existing collections such as `A_Recursion`, `B_LinkedList`, `B_Sorting`, and `C_Stack` intact.
3. Store a problem once; company index entries are tags, not duplicate solutions.
4. Use Java for interview implementations.
5. Use LeetCode as primary, Code360 (if this is the intended platform) and GeeksforGeeks as supporting platforms.
6. A historical checkbox is not proof of current independent mastery: re-test before upgrading status.
7. Create one pattern file when starting a pattern; don't create a separate Markdown file per problem.
