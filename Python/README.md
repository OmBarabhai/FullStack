## 💻 **Basic Example**

```python
# Variables
name = "Python"
version = 3.10

# Functions
def greet(name):
    return f"Hello, {name}!"

# Classes
class Person:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        return f"I am {self.name}"

# Usage
print(greet(name))
person = Person("Alice")
print(person.introduce())
```
