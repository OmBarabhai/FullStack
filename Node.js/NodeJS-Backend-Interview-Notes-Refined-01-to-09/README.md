# Node.js & Backend Interview Notes — Lectures 01–09

These are concise, interview-oriented revision notes. Each lecture is a separate Markdown file with focused definitions, a diagram or flow, tables where comparison helps, and interview checks.

## Suggested order

1. Node.js runtime and V8
2. Processes, threads and concurrency
3. Node.js threading model
4. libuv, event loop and microtasks
5. Modules, CommonJS, ESM and npm
6. File I/O, paths and rendering
7. Networking, DNS, TCP/IP and ports
8. Storage, latency and scaling
9. HTTP, APIs and REST

Lecture 04 contains the single worked code dry run, to keep the pack from repeating similar walkthroughs. Code examples elsewhere are short illustrations only.
